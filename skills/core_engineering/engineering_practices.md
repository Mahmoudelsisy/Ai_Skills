# Professional Engineering Practices | الممارسات الهندسية الاحترافية

## Arabic Description | وصف بالعربية
قواعد عامة وشاملة للممارسات الهندسية التي تشمل التعاون، مراجعة الكود، والتفكير التحليلي قبل البدء بالبرمجة.

---

## Strict Rules | قواعد صارمة

### 1. Thinking Before Coding
- **Plan First**: Always create a plan or pseudocode before implementing complex logic.
- **Traceability**: Ensure every change can be traced back to a specific problem or requirement.

### 2. Code Review Standards
- **Objective Reviews**: Review code based on logic, performance, and security, not personal preference.
- **Constructive Feedback**: Provide actionable feedback that helps the author improve.

### 3. Testing & Verification
- **Automated Verification**: Run the full test suite before every commit.
- **Manual Verification**: Test the feature manually in a staging-like environment if possible.

### 4. Problem Solving
- **Root Cause Analysis**: Don't just fix the symptoms; find and fix the underlying cause of a bug.
- **Impact Assessment**: Before making a change, evaluate its impact on other parts of the system.

### 5. Learning & Improvement
- **Post-Mortems**: Conduct post-mortems for major failures to prevent them from recurring.
- **Best Practices**: Stay updated with the latest industry standards and incorporate them into the workflow.
