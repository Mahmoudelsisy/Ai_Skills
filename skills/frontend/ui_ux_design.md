# UI/UX Design & User Experience | تصميم واجهة وتجربة المستخدم

## Arabic Description | وصف بالعربية
قواعد صارمة لتصميم تجارب مستخدم مذهلة وواجهات برمجية سهلة الاستخدام. تركز هذه القواعد على الاتساق البصري، سهولة الوصول، والبحث الموجه بالمستخدم.

---

## Strict Rules | قواعد صارمة

### 1. Visual Consistency
- **Design System**: Strictly adhere to the established design system (colors, typography, spacing, components).
- **Grid & Alignment**: Use a consistent grid system (e.g., 8pt grid) for all layouts.

### 2. User Experience (UX)
- **Ease of Use**: Minimize the number of steps required for the user to complete their primary task.
- **Feedback**: Provide immediate visual feedback for every user interaction (e.g., loading states, button presses).
- **Error Messages**: Use clear, non-technical, and helpful error messages that guide the user on how to fix the issue.

### 3. Accessibility (a11y)
- **WCAG Compliance**: All designs MUST meet WCAG 2.1 Level AA standards.
- **Screen Reader Support**: Ensure all interactive elements have proper labels for screen readers.
- **Color Contrast**: Maintain a minimum contrast ratio of 4.5:1 for normal text.

### 4. User Research & Testing
- **User-Centric**: Every design decision MUST be backed by user needs or data, not just aesthetics.
- **Prototyping**: Create high-fidelity prototypes to test complex interactions before implementation.

### 5. Design Handover
- **Documentation**: Provide clear documentation for animations, edge cases, and responsive behavior to developers.
- **Asset Management**: Ensure all assets (icons, images) are exported in optimized formats (SVG, WebP).
