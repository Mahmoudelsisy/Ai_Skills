# Technical SEO & Web Performance | تحسين محركات البحث والأداء التقني للويب

## Arabic Description | وصف بالعربية
قواعد صارمة لتحسين محركات البحث (SEO) تقنياً وضمان أداء الويب الفائق. تركز هذه القواعد على مؤشرات أداء الويب الأساسية (Core Web Vitals)، سهولة الزحف (Crawlability)، وتصدر نتائج البحث.

---

## Strict Rules | قواعد صارمة

### 1. Core Web Vitals (CWV)
- **LCP (Largest Contentful Paint)**: Ensure main content loads in under 2.5 seconds.
- **FID (First Input Delay)**: Optimize JavaScript execution to ensure interactivity under 100ms.
- **CLS (Cumulative Layout Shift)**: Avoid layout shifts. Use explicit dimensions for images and ads.

### 2. Crawlability & Indexing
- **Robots.txt & Sitemap**: Maintain an accurate `robots.txt` and dynamic `sitemap.xml`.
- **Semantic Structure**: Use proper header hierarchy (H1-H6). Each page MUST have exactly one H1 tag.
- **Canonical Tags**: Use canonical tags to prevent duplicate content issues.

### 3. Metadata & Structured Data
- **Tags**: Every page MUST have unique, optimized Meta Titles and Descriptions.
- **Schema.org**: Implement JSON-LD structured data to help search engines understand content context.

### 4. Technical Performance
- **Server Response Time (TTFB)**: Optimize server response times to be under 200ms.
- **Mobile Friendliness**: All pages MUST be fully responsive and pass Google's Mobile-Friendly Test.
- **HTTPS**: Site MUST be served over HTTPS.

### 5. Images & Media
- **Alt Text**: Every image MUST have descriptive, keyword-relevant Alt Text.
- **WebP/AVIF**: Use modern image formats for better compression without quality loss.
