# Software Licensing, IP & Open Source Stewardship | تراخيص البرمجيات والملكية الفكرية وقيادة المشاريع مفتوحة المصدر

## Arabic Description | وصف بالعربية
قواعد هندسية وقانونية لإدارة تراخيص البرمجيات، حماية الملكية الفكرية (IP)، وقيادة المشاريع مفتوحة المصدر باحترافية. تركز القواعد على فهم أنواع التراخيص (GPL, MIT, Apache)، الامتثال القانوني، وأفضل ممارسات الحوكمة في المجتمعات البرمجية.

---

## Strict Rules | قواعد صارمة

### 1. License Compliance
- **Scan Dependencies**: Use automated tools (e.g., FOSSA, Snyk License Compliance) to scan all dependencies for license compatibility.
- **Copyleft Awareness**: Strictly manage the use of Copyleft licenses (GPL, AGPL) in proprietary commercial software to avoid unintended source code disclosure requirements.

### 2. Intellectual Property (IP) Management
- **Contributor License Agreements (CLA)**: Require a signed CLA for all external contributions to ensure the project has the necessary rights to use and distribute the code.
- **Copyright Headers**: Ensure every source file has a standard, accurate copyright and license header.

### 3. Open Source Stewardship
- **Governance Model**: Clearly define the governance model (e.g., Benevolent Dictator, Steering Committee) for the project.
- **Community Conduct**: Enforce a strict Code of Conduct (CoC) to maintain a healthy and inclusive community.

### 4. Vulnerability Disclosure
- **Security Policy**: Maintain a clear `SECURITY.md` file explaining how to report vulnerabilities privately. NEVER disclose vulnerabilities publicly until a patch is ready.

### 5. Project Health & Maintenance
- **README Excellence**: Every project MUST have a high-quality README with installation, usage, and contribution guides.
- **Changelog Standards**: Maintain an accurate, manually curated `CHANGELOG.md` following the "Keep a Changelog" standard.
